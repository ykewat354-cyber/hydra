# T03(b) no-gates allowlist — one regex per line, matched with re.search against
# the full text of a grep hit line while scanning hydra/ with:
#   input\(|getpass|\[y/N\]|\[Y/n\]|are you sure|confirm|approve|proceed\?|denylist|blocklist|blacklist|dangerous|forbidden
# Everything from "#" to end of line is a comment. A hit is allowed only when at
# least one pattern below matches it; any other hit fails tests/test_wo1_audits.py.
# Keep patterns anchored to the whole line so a new gate cannot piggyback on one.
#
# --- allowed: the only blocking human-input path (the REPL prompt, cli.py) ---
^\s*task = input\("task> "\)\.strip\(\)$
#
# --- false positives: the "input\(" regex also matches these method names ---
^\s*self\._digest_input\(old_msgs\)\)$
^\s*tail = self\._digest_input\(self\.messages\[-12:\]\)\[:7000\]$
^\s*def _digest_input\(msgs: list\) -> str:$
^\s*self\.submit_input\(\)$
^\s*def submit_input\(self\):$
#
# --- allowed: prompt sentence that forbids confirmations (instruction text,
# --- never an execution gate; the audit scans prompts/ too) ---
